Hi — quick guide for the two Documents items in 03 – Documents:

*Page header & footer*
This is optional text at the top and bottom of a page (like letterhead). It’s separate from the main document text and from the section list on the right.

To edit on one page:
• Open the document
• Click Edit Document
• Stay on the Content tab
• You’ll see Page header above the main text and Page footer below — click in and type
• Click Save

Other way: on Content tab, click Page layout (top right) → edit on Properties tab → Save

For all pages in a folder: right-click the folder → Page layout defaults

---

*On this page (section list on the right)*
This is the jump list on the right side. It’s built from headings inside the document — not the page header/footer.

To turn it on:
• Open the document → Content tab
• Add Heading 1, Heading 2, or Heading 3 in the body (toolbar, or type / and pick a heading)
• On a wide screen, On this page shows on the right (on smaller screens it’s at the top)

To show or hide it: Show sections / Hide sections (top right on Content tab)

If nothing appears, the page needs at least one real heading — bold normal text won’t create sections.

---

In short:
• Header/footer = top & bottom of the page → Edit Document, or Page layout
• On this page = sections from headings in the body → add H1/H2/H3
