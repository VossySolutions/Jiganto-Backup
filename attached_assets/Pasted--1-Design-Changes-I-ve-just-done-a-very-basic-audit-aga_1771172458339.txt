Again I welcome any suggested changes to the above based on best practice.  DOCUMENTS MODULE - the document module is probably more understood and known by users however we still need to be consistent with the head asexual and the one idea I had to provide some consistency with the tabs whilst still keeping the Explorer folder because this is unique and powerful is the ability to have tabs where the first tab is as follows:  ALL Documents  or All Docs
My Documents  or My  Docs
Business Documents  or Business Docs
Customer Documents  or Customer Docs
Project Documents  or Project Docs
Finance Documents  or Finance Docs
Testing Documents  or Testing Docs
BPM Documents  or BPM Docs

The thought process is that when users create documents in the other modules, they are automatically tagged with the module name, so for example if I create a project document it automatically has Project as a tag or if I create a document in the testing module it has testing as a tag. And when users go to the documents module, they can flick between the different tabs which means the explorer on the left-hand side will then only show the documents that were created in those respective modules. The idea here is that users can go to the dedicated document management module and see the different documents based on the modules. There will of course be other documents that might not be relevant to the modules and they can be seen and filtered on through the ALL Docs tab.
 
Again, I welcome your input as to whether you think based on best practice this would be a good user experience or not, but my thought process was that it ties together all the documents from the modules and makes it easy for the user to navigate and find
