Here's a breakdown of every design decision and some additional recommendations beyond what's shown in the panel itself.
The six core changes and their rationale:
1. Search at the top. This is the single most impactful addition. As soon as someone has more than about 15 documents across folders, they stop browsing and start searching. The current design forces users to expand folders manually. A persistent search box at the top of the explorer solves this entirely and is the pattern used by Notion, Confluence, Google Drive, and every modern document tool.
2. Quick-access chips replace the plain "Favourites / Recent" section headers. In the current design these headings are styled identically to everything else — they don't feel actionable. Pill chips immediately read as filters you can click, which is what they actually are.
3. Recent documents as proper cards. The current list is flat text with identical file icons for every item. The redesign gives each recent doc a coloured icon badge (differentiated by document type), a last-edited timestamp, and an inline status pill (Draft, Published, etc.). The active document gets a tinted background highlight — clear and unambiguous.
4. Colour-coded folder icons. The numbered prefixes (01, 02, 03...) are a symptom of a missing visual hierarchy — users are compensating for the fact that all folders look identical by numbering them. With contextual icons in distinct colour families, you remove the need for numbers entirely. Users build spatial memory — "finance is the amber one" — which makes navigation faster over time.
5. Promoted action bar footer. "New Page" is arguably the most frequent action in the document module, yet in the current design it sits as a plain grey text link at the very bottom. The redesign gives it a primary button treatment (indigo, filled) that matches the button already in the top toolbar. This creates a consistent, discoverable action wherever the user's focus sits.
6. Removed redundancy. "Unfiled Documents" appearing as a separate section below the folder list is confusing — it reads like an eighth folder. The redesign either eliminates it (unfiled docs surface through the Recent list or Search) or collapses it into the folder list as a neutral-coloured "Uncategorised" entry.
Two further suggestions beyond the panel itself: the current top tab bar (All Docs / My Docs / Business / Customer / Project...) duplicates the folder structure. You could either remove the tabs and rely on the improved explorer, or keep the tabs and hide the corresponding folder from the tree when a tab is active, to avoid the cognitive load of two parallel navigation systems. Second, adding a right-click context menu on folders and documents (Rename, Move, Share, Copy link, Delete) would significantly speed up power-user workflows that currently require navigating away from the panel.Sonnet 4.6
