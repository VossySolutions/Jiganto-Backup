Jiganto Conditional Formatting — Requirements Specification
1️⃣ Objective

Implement a reusable Conditional Formatting Framework for Jiganto data grids and tables that allows users to define rules that automatically format:

Cells

Rows

Columns

Entire records

based on configurable conditions applied to field values.

The feature must work across all Jiganto modules and support small, medium, and large datasets.

2️⃣ Scope of Capability

Conditional formatting must support:

Numeric fields

Text fields

Dates

Status fields

Boolean fields

Calculated fields

Lookup / reference fields

Formula results

Formatting should update:

In real-time on data load

After edits

After recalculation

After filter/sort

After API refresh

3️⃣ User Stories
End User

I can define rules like Excel conditional formatting

I can highlight values above/below thresholds

I can color rows based on status

I can flag overdue items

I can apply multiple rules

I can prioritize rules

I can preview formatting before saving

Admin

I can define rules globally per module

I can create reusable rule templates

I can apply rules to all users or selected roles

9️⃣ Rule Storage Model (Replit Implementation)

Rules stored as JSON objects.

Example Rule JSON
{
  "ruleId": "CF-001",
  "name": "Highlight High Amount",
  "scope": "cell",
  "field": "amount",
  "condition": {
    "operator": ">",
    "value": 10000
  },
  "format": {
    "backgroundColor": "#FFE0E0",
    "textColor": "#B00020",
    "bold": true
  },
  "priority": 1,
  "enabled": true
}
