The Jiganto Gantt is purpose-built for professional services firms, system integrators, software teams and enterprise project managers. Here is the complete feature set.

📅
Interactive Gantt Timeline
A fully visual project timeline where every bar is live and interactive — representing task duration, progress and health at a glance.
  • Drag any bar left or right to move its dates
  • Grab the right edge to extend or shorten a task
  • Grab the left edge to move the start date independently
  • Progress fill shown directly inside each bar
  • All dates update in real time as you drag
📝
Inline Cell Editing
Update any task attribute directly in the row. No need to open a separate window for routine updates — everything edits in place.
  • Name — double-click to edit in the row
  • Owner — single click opens a team dropdown
  • Start & end dates — single click opens a date picker
  • Progress — single click opens an inline 0–100% slider
  • RAG status — single click cycles Green → Amber → Red
🔗
Task Dependencies
Link tasks to reflect real-world sequencing. Arrows connect precisely to the edges of bars with clear dep type labels.
  • Three types: Finish-to-Start, Start-to-Start, End-to-End
  • Visual draw mode: click source bar then target bar
  • Arrows use elbow routing to avoid obscuring bars
  • Dep type badge shown on each arrow
  • Click any arrow to edit the linked task
⚡
Critical Path Highlighting
One click reveals the sequence of tasks that directly determines the project end date — showing exactly where schedule risk lies.
  • Toggle on/off with the ⚡ Critical Path button
  • Critical task rows get a red left border
  • Critical bars outlined in red on the timeline
  • Critical dependency arrows turn solid red
  • Computed from the live dependency network
🔢
Auto-Calculated WBS Numbers
Work Breakdown Structure numbers are computed automatically from the task hierarchy — you never set them manually.
  • Hierarchical numbering: 1, 1.1, 1.1.1 etc.
  • Updates instantly when tasks are moved or rearranged
  • Used as the reference ID in import and export files
  • Visible in a dedicated WBS column on the left panel

Work structure

Seven levels of
structured hierarchy

Jiganto Gantt supports everything from a single small project to a complex multi-year programme — using one consistent structure that scales with you.

🔷 Programme
The top-level container — a collection of related projects working toward a common strategic outcome. E.g. Digital Transformation Programme 2025–2027
📁 Project
A time-bound effort with defined scope and deliverables. E.g. SAP S/4HANA Core ERP Implementation
📋 Phase
A defined stage of the project. E.g. Discovery · Solution Design · Build · Testing · Go-Live
🔀 Workstream
A parallel track within a phase. E.g. Finance & Controlling · Supply Chain · Integrations & Data Migration
⚡ Activity
A grouping of related tasks within a workstream. E.g. GL / AP / AR Configuration · Asset Management Setup
☑ Task / Sub-Task
The individual unit of work assigned to a person. E.g. Configure chart of accounts · Set up payment terms
◆ Milestone
A key delivery moment shown as a diamond on the timeline. E.g. Go-Live · UAT Sign-Off · Design Sign-Off · Project Complete
Dependencies

Three dependency types
for any sequence

Choose the right relationship when linking tasks. Arrows connect precisely to the correct edge of each bar and are labelled with the dependency type.

FS
Finish to Start
Task B cannot start until Task A has finished. The most common type — used for sequential activities where one must complete before the next begins.
Example: Testing cannot start until Build is complete
Build
Test
SS
Start to Start
Task B cannot start until Task A has started. Used for parallel activities that must begin together but can run at different lengths.
Example: Training can only start once Build has started
Build
Training
EE
End to End
Task B cannot end until Task A has ended. Applied to review gates, sign-offs and parallel workstreams that must complete together.
Example: Documentation must finish when UAT finishes

Health tracking

RAG status — at every level

Every task, phase, workstream, project and programme carries a health indicator. Set it with one click, see it everywhere instantly.

Green — On Track
Work is progressing as planned. No action required. Visible as a green dot in the task row and reflected in the progress bar colour and bar styling.
Amber — At Risk
A concern has been identified that may impact delivery if not addressed. Action needed. Items should carry a note in the task notes field explaining the risk and the mitigation plan.
Red — Behind
The task or phase is behind schedule or over budget. Immediate escalation and corrective action required. Red items surface automatically in project dashboards and portfolio-level alerts.
