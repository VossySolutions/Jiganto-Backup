What's new in v2
Gap fixes (the 5 you identified)
1. WBS column — auto-calculated. A dedicated WBS column now sits at the left of the task panel, 52px wide. The numbering is computed automatically on every render using the parent-child tree — top-level items get 1, 2, 3, their children get 1.1, 1.2, 2.1, and so on recursively. You never set a WBS manually — it always reflects the actual hierarchy. It's also used by the import/export system as the link between rows.
2. Full 7-level hierarchy — Programme → Project → Phase → Workstream → Activity → Task → Milestone. Each level has its own type icon (🔷 📁 📋 🔀 ⚡ ☑ ◆), its own background colour on the row, its own bar height on the timeline (Programme bars are tallest, Task bars thinnest), and its own colour identity. The demo data shows all seven levels in use — the SAP programme contains two projects, the core ERP project contains eight phases, the Build phase contains three workstreams, the Finance workstream contains three activities, and the GL activity contains three tasks, with four milestones across the plan.
3. Dependency type picker — FS / SS / EE. In the edit modal, below the predecessor dropdown, there are three buttons: FS (Finish-to-Start), SS (Start-to-Start), EE (End-to-End). The selected type is stored per dependency and affects both the arrow drawing logic and the label shown on the dependency line on the timeline. FS arrows connect the end of the predecessor to the start of the successor. SS connects start-to-start. EE connects end-to-end.
4. Critical path highlight. The toolbar has a ⚡ Critical Path toggle button. When active, it computes the longest path through the dependency network (the sequence of tasks with the latest end date), highlights those rows in the task panel with a red left border and red task name, highlights those bars on the timeline with a red outline, and turns the dependency arrows between critical tasks from dashed grey to solid red. Clicking the button again removes all highlighting.
5. Horizontal scroll. The right timeline panel now scrolls independently left-right via native overflow scroll. The month/day header is position: sticky; top: 0 so it stays visible while scrolling vertically. The left task panel and the timeline scroll vertically in sync (using a lock flag to prevent infinite loop) — scroll either side and the other follows. The 📍 Today button scrolls the timeline to centre on today's date.

Next-level features (the 3 you added)
6. Filter on any level. The toolbar has a FILTER section with three dropdowns: Level (Programme / Project / Phase / Workstream / Activity / Task / Milestone), Owner, and RAG status. They work together — you can filter to show only At Risk Tasks owned by Nina Okafor, for example. Collapsed children are still hidden regardless of filter. This lets you present just the Phase-level view to a steering committee, or just the Task-level view for a daily standup.
7. Export template. The green ↓ Export button opens a modal with two actions. "Download empty template" gives you a CSV with the correct column headers and one example row — open it in Excel, populate your project plan, save as CSV, and import. "Export current plan" downloads the full live Gantt as a CSV, with all WBS numbers, dates, RAG statuses, dependency links (by WBS), dep types, and notes. The column definitions are documented in the same modal so users know exactly what each field means.
8. Import — Append or Overwrite. The ↑ Import button opens the import modal with two mode buttons at the top: Append (adds imported tasks to the existing plan — useful for adding a new workstream) and Overwrite (replaces everything — useful for a full plan refresh). Overwrite shows a yellow warning banner. The file upload accepts drag-and-drop or click-to-browse. The parser handles quoted CSV fields, maps parent and predecessor relationships by WBS number, validates required fields, and skips bad rows with a count. After import it shows a green success message with how many items were added.
