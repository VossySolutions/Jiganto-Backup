⛓ Dependency Types
FS Finish → Start (most common)
B cannot start until A has finished.
A ████████ ↓ B ████████
SS Start → Start
B cannot start until A has started. They run in parallel.
A ████████ B ████████ ↑ same start (or later)
FF Finish → Finish
B cannot finish until A has finished. End dates are linked.
A ████████ B ████████ ↑ same finish (or later)
💡 Tip: FS covers ~90% of real projects. Use SS when two tasks must start together, FF when one task's end gates another's completion. Moving bars is manual — dependencies show relationships but don't auto-reschedule dates.
