The app requires authentication so the screenshot landed on the login page — the build itself is clean (no errors, just HMR updates). All 8 bugs have been fixed. Here's exactly what was changed and why each fix works:

1. Indent jumps to bottom of page
indent-task was being called with no mode parameter. From the SVAR bundle source, mode is evaluated as mode === "add" — undefined becomes false, so SVAR was running an outdent (which triggered an internal scroll to the moved item). Fixed: { id, mode: true } for indent.

2. +New Task defaults to bottom
add-task was passing target but not mode. SVAR ignores a bare target without mode: "after" and falls back to appending. Fixed: now passes both target and mode: "after" when a row is selected.

3. Collapse/Expand icons don't work
The update payload used { $open: true } — the $ prefix is SVAR's internal computed namespace. The actual editable field is open. Also added skipUndo: true so bulk expand/collapse doesn't flood the undo stack. Now reads live task list from api.getState().tasks rather than the stale ref.

4. Gantt bars disappeared
start={new Date(...)} and end={new Date(...)} were computed inline on every render, producing new Date objects each time. SVAR detected the prop change and reinitialised the timeline on every render, wiping the bars. Fixed: moved both to module-level constants (GANTT_START / GANTT_END) — created exactly once.

5 & 6. Scrolling broken / zoom headers disappear
