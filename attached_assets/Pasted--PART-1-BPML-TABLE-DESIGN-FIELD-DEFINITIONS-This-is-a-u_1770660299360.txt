🧱 Core BPML Identity Fields

These define the process hierarchy and structure.

Field	Type	Required	Description
bpml_id	string	✅	Unique ID (e.g. O2C-L3-001)
process_code	string	✅	Structured code
process_name	string	✅	Process title
process_description	text	✅	Description
level_1	string	✅	End-to-End (O2C, P2P, RTR, HTR)
level_2	string	✅	Process Group
level_3	string	✅	Business Process
level_4	string	optional	Subprocess
level_5	string	optional	Task
parent_id	string	optional	Parent BPML ID
sequence_order	number	optional	Order in flow
