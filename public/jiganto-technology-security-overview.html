2 Technology Stack

Jiganto is built on a modern, enterprise-grade technology stack chosen for performance, scalability, and long-term maintainability.

▣ Frontend

React with TypeScript, Vite build system, TailwindCSS, and Shadcn UI component library. Supports 8 distinct data view types including Kanban, Gantt, Calendar, and more.

⚙ Backend

Node.js with Express.js and TypeScript. RESTful API architecture with WebSocket support for real-time features such as chat and live collaboration.

☃ Database

PostgreSQL relational database with Drizzle ORM for type-safe database operations, migrations, and schema management.

❖ AI Integration

OpenAI GPT models integrated via secure API connections for template generation, intelligent assistance, and workflow automation.

Why this stack? TypeScript across the full stack ensures type safety and reduces bugs. PostgreSQL is the most trusted enterprise-grade open-source database. React provides a responsive, modern user experience. This combination is used by leading technology companies worldwide.

Data Residency Architecture

  • Tenant-level data isolation — each customer's data is fully separated at the database level with no cross-tenant data leakage
  • Regional tenant routing — the platform architecture supports assigning tenants to specific regional database clusters
  • Data residency flags — tenant configuration includes data residency metadata to enforce where data is stored and processed
  • Cross-region portability — when needed, data can be securely migrated between regions with full audit trails

Commitment: For customers with specific data residency requirements in regions not yet available, we offer dedicated deployment arrangements to ensure compliance with local data protection laws. Contact us to discuss your specific needs.

Encryption & Data Protection

  • Data in transit — all communications secured with industry-standard TLS 1.2+ encryption
  • Data at rest — AES-256 server-side encryption for all stored data, managed by Google Cloud SQL
  • Database encryption — automatic encryption and secure key management via Google Cloud Key Management Service
  • Secret management — API keys, credentials, and sensitive configuration stored in encrypted vaults, never in source code

Infrastructure Security

  • Private networking — all data-processing components operate within a private network in a secure cloud environment
  • Web Application Firewall (WAF) — active protection against malicious traffic, SQL injection, XSS, and other common attacks
  • Load balancing — automatic traffic distribution for high availability and DDoS protection
  • Vendor security — rigorous due diligence on all subprocessors and third-party integrations
  • Continuous monitoring — dedicated security teams monitoring infrastructure and application security around the clock

Application Security

  • Authentication — enterprise-grade authentication with reCAPTCHA, fraud prevention, and multi-factor authentication (MFA) support
  • SAML Single Sign-On — seamless integration with your existing Identity Provider (Okta, Azure AD, Google Workspace, etc.)
  • SCIM provisioning — automated user provisioning and deprovisioning synced with your identity management system
  • Role-based access control — granular permissions at module, feature, and data levels with custom role definitions
  • Project-scoped access — customer and external users can be restricted to specific projects with defined access levels (view, contribute, manage)
  • Security scanner — automated vulnerability detection including CVE scanning, dependency analysis, SBOM export, and static code analysis
  • Audit logging — comprehensive audit trails for all data access, modifications, and administrative actions

7 Multi-Tenancy & Data Isolation

Jiganto is designed from the ground up as a multi-tenant platform with strict data isolation guarantees.

  • Database-level isolation — every customer (tenant) has their data logically separated; queries are always scoped to the authenticated tenant
  • Authentication boundary — every API request is authenticated and authorised before accessing any data; cross-tenant access is architecturally impossible
  • Configurable per tenant — each tenant can have independent settings for modules, branding, roles, permissions, and workflows
  • Data portability — tenants can export their data in standard formats (CSV, Excel, PDF) at any time, supporting data portability requirements
  • Tenant-specific user management — three user types (Employee, Contractor, Customer) with independent access controls and assignment management per tenant

8 Frequently Asked Questions

Is our data shared with other customers?

No. While the application infrastructure is shared (standard SaaS model), every customer's data is fully isolated at the database level. There is no mechanism for one tenant's data to be accessed by another tenant.

Can we use our existing SSO / identity provider?

Yes. Jiganto supports SAML-based Single Sign-On and SCIM-based user provisioning, allowing seamless integration with identity providers such as Okta, Azure Active Directory, Google Workspace, and others.

What happens to our data if we cancel our subscription?

You can export all your data in standard formats (CSV, Excel) at any time. Upon cancellation, we provide a data retention period during which you can retrieve your data before it is securely deleted.

Is the platform hosted on AWS, Azure, or Google Cloud?

Jiganto is currently hosted on Google Cloud Platform (GCP). The platform architecture is cloud-agnostic, meaning it can be deployed on AWS, Azure, or GCP based on customer requirements for dedicated or private cloud arrangements.

Can we have our data hosted in our own country?

Currently, standard hosting is available in the United States and India. For customers requiring hosting in the UK, Europe, or other regions, we offer dedicated deployment arrangements. Our architecture fully supports regional data residency. Please contact us to discuss your specific requirements.

How do you handle security vulnerabilities?

We employ automated security scanning (CVE detection, dependency vulnerability analysis, static code analysis), dedicated security teams for continuous monitoring, and follow responsible disclosure practices. Enterprise customers have access to a Security Centre dashboard with full visibility into their security posture.
